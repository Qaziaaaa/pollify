Pollify Backend Architecture

Complete guide to understand the flow, connections, and purpose of every file

Project Overview

Pollify is a polling app backend where users can create polls, vote, comment, and bookmark.

Folder Structure

📁backend/- Root folder
📄server.js- Entry point. Starts the server.
📄.env- Secret keys (DB, JWT, API keys)
📁config/- Setup external services
📄db.js- MongoDB connection
📄cloudinary.js- Image upload setup
📄mailer.js- Email service setup
📁models/- Database schemas (blueprints)
📄User.js- User schema + password hashing
📄Poll.js- Poll + embedded Vote schema
📄Comment.js- Comment schema (with replies)
📁middleware/- Runs BEFORE controllers
📄auth.js- Verifies JWT token
📁controllers/- Business logic
📄authController.js- Register, Login, Verify, Profile
📄passwordController.js- Forgot + Reset password
📄pollController.js- Create, View, Vote, Delete polls
📄commentController.js- Add, View, Delete comments
📄bookmarkController.js- Bookmark/Unbookmark polls
📁routes/- Maps URLs to controllers
📄authRoutes.js- /api/auth/* routes
📄pollRoutes.js- /api/polls/* routes
📁utils/- Small helper tools
📄generateOTP.js- 6-digit OTP generation
📄mailer.js- Sends emails

Complete Request Lifecycle

What Happens When You Make a Request

Frontend sends HTTP request
fetch("http://localhost:5000/api/auth/login", { method: "POST", body: { email, password } })
server.js receives the request
Express matches the URL pattern to a route file
app.use("/api/auth", authRoutes) // routes to authRoutes.js
Route file matches exact URL
authRoutes.js finds matching route and its handler function
router.post("/login", login) // POST + /login = login()
Middleware runs (if applied)
auth.js checks for JWT token. If protected route and no token = blocked.
router.get("/profile", auth, getProfile) // auth runs first
Controller handles logic
Does the actual work: validate input, check DB, create data, etc.
const user = await User.findOne({ email }) // find user in DB
Model talks to MongoDB
Mongoose translates JavaScript to database commands
await User.create({ name, email, password }) // inserts into MongoDB
Response sent back
Controller sends JSON response to frontend
res.json({ token, user }) // frontend receives this

All Files - Purpose & Functions

config/ - External Service Setup

config/db.js

MongoDB Connection

Connects your app to the database. Uses URI from .env.
connectDB()
Async function that calls mongoose.connect(). If it fails, stops the server.
config/cloudinary.js

Image Upload Service

Connects to Cloudinary for image hosting.
cloudinary.config({...})
Sets up Cloudinary with API keys from .env.
upload
Multer middleware that catches file uploads and stores in memory.
uploadToCloudinary(buffer)
Takes image buffer, uploads to Cloudinary, returns the URL.
config/mailer.js

Email Service Connection

Creates SMTP transporter for sending emails.
transporter
Nodemailer transport object configured with SMTP host, port, auth from .env.

models/ - Database Schemas

models/User.js

User Schema

Defines user data structure with password hashing.
userSchema.pre("save")
Hook that runs before every save. Hashes password if modified.
userSchema.methods.matchPassword()
Instance method. Compares entered password with stored hash. Returns true/false.
models/Poll.js

Poll Schema (with embedded Votes)

Defines poll structure. Votes are embedded inside polls.
voteSchema
Sub-schema embedded inside Poll. Each vote = user + value.
pollSchema
Main schema with creator, question, type, options, votes array.
models/Comment.js

Comment Schema

Defines comment structure with nested replies.
commentSchema
Fields: user, poll, text, parentComment (self-reference for replies).

middleware/ - Request Interceptors

middleware/auth.js

JWT Authentication Middleware

Runs BEFORE protected controllers. Verifies JWT token.
auth(req, res, next)
Extracts token from headers, verifies with JWT_SECRET, attaches userId to request, calls next().

controllers/ - Business Logic

controllers/authController.js

Authentication Logic

Handles user registration, login, OTP verification, profile.
register(req, res)
Creates user, uploads avatar, generates OTP, sends verification email.
verifyOtp(req, res)
Verifies OTP, marks user as verified, clears OTP.
login(req, res)
Checks credentials + verification status, returns JWT token.
getProfile(req, res)
Returns logged-in user's profile (protected route).
controllers/passwordController.js

Password Reset Logic

Handles forgot password and reset with OTP.
forgotPassword(req, res)
Finds user, generates OTP, saves it, sends OTP email.
resetPassword(req, res)
Verifies OTP, sets new password, clears OTP.
controllers/pollController.js

Poll CRUD Logic

Create, read, vote, delete polls.
createPoll(req, res)
Creates new poll with question, type, options.
getPolls(req, res)
Returns all polls sorted newest first. Populates creator details.
getPoll(req, res)
Returns single poll by ID. Increases view count.
votePoll(req, res)
Adds/updates vote. Checks if already voted and if poll is closed.
deletePoll(req, res)
Deletes poll. Only creator can delete their own polls.
controllers/commentController.js

Comment Logic

Add, view, delete comments on polls.
addComment(req, res)
Adds comment to poll. Supports nested replies via parentComment.
getComments(req, res)
Returns all comments for a poll with user details.
deleteComment(req, res)
Deletes comment. Only comment author can delete.
controllers/bookmarkController.js

Bookmark Logic

Bookmark/unbookmark polls.
bookmarkPoll(req, res)
Toggle: if already bookmarked removes it, otherwise adds it.
getBookmarks(req, res)
Returns all bookmarked polls with full details (nested populate).

routes/ - URL Mapping

routes/authRoutes.js

Auth Routes

Maps auth-related URLs to controller functions.
POST /register, /verify, /login
Public routes - no auth needed.
GET /profile, /bookmarks
Protected routes - auth middleware required.
POST /forgot-password, /reset-password
Public routes - for password recovery.
routes/pollRoutes.js

Poll Routes

Maps poll-related URLs to controller functions.
GET / and /:id
Public - anyone can view polls.
POST /, /:id/vote, /:id/comments, /:id/bookmark
Protected - must be logged in.
DELETE /:id
Protected - only poll creator can delete.

utils/ - Helper Tools

utils/generateOTP.js

OTP Generator

Creates 6-digit verification codes.
generateOTP()
Returns random 6-digit string like "482917".
expireOTP()
Returns Date object 10 minutes from now.
otpValid(user, otp)
Checks if OTP matches AND hasn't expired.
utils/mailer.js

Email Sender

Sends emails using the transporter from config/mailer.js.
sendMail({ to, subject, text })
Sends email. Returns true if sent, false if failed.

Vote on Poll

Frontend
POST /api/polls/:id/vote
→
auth
Verify token
→
votePoll
Check if closed, check existing vote
→
poll.votes
Push/update vote
→
Response
{ poll }

Vote Logic Inside Controller

Find poll by ID
Check if poll is closed -> reject if yes
Check if user already voted -> update their vote
If new voter -> push vote to votes array
Save poll to MongoDB

Delete Poll

Frontend
DELETE /api/polls/:id
→
auth
Get userId
→
deletePoll
Check creator === userId
→
poll.deleteOne()
Remove from DB
Key concept: Votes are embedded in the Poll document, not separate. This is faster because poll + votes load together in one query.
