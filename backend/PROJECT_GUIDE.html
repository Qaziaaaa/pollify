📊 OpinionHub — Full-Stack Architecture Guide

Complete walkthrough of the polling application — frontend, backend, data flow & every file

🐍 Express.js 🍃 MongoDB + Mongoose ⚛️ React 19 🔐 JWT Auth

📋 Project Overview

OpinionHub is a full-stack polling platform where users can register, create polls across 5 types (Yes/No, Single Choice, Rating, Image-based, Open-ended), vote, comment with threaded replies, bookmark polls, follow other users, and receive real-time notifications.

Tech Stack

🖥️ Backend

Runtime: Node.js + Express.js
Database: MongoDB via Mongoose ODM
Auth: JWT (jsonwebtoken) + OTP via Nodemailer
Media: Cloudinary + Multer for image uploads
Security: Helmet, CORS, Rate Limiting, bcryptjs

🎨 Frontend

Framework: React 19 (Vite)
Routing: React Router v7
Styling: Tailwind CSS v4
State: React Context (Auth, Toast)
Icons: Lucide React
HTTP: Fetch API via custom wrapper

Core Features

👤 Authentication

Register with email OTP, login, password reset via OTP, profile management with avatar upload, JWT session

🗳️ Poll System

5 poll types (Yes/No, Single, Rating, Image, Open). Create, vote, unvote, edit, close/reopen, delete. Auto-computed results.

💬 Comments

Threaded comments with nested replies. Users can comment, reply, and delete their own comments on any poll.

🔖 Bookmarks

Toggle bookmark on polls. Dedicated saved-polls page. Bookmark set computed via user's embedded array.

👥 Follow System

Follow/unfollow users. Feed filter by "following" to see polls from people you follow only.

🔔 Notifications

Real-time notifications for votes, comments, and follows. Unread count badge. Mark read individually or all at once.

Architecture at a Glance

🖥️ Backend — Server & API

server.js — Entry Point

The Express server initializes in a strict order:

// 1. Import dependencies
import express from "express";
import cors from "cors";
import helmet from "helmet";

// 2. Connect to MongoDB
connectDB();

// 3. Security middleware
app.use(helmet());
app.use(cors({ origin: process.env.CORS_ORIGIN }));
app.use(express.json({ limit: "10kb" }));

// 4. Rate limiting on auth endpoints (20 req / 15 min)
app.use("/api/auth/login", authLimiter);

// 5. Mount route groups
app.use("/api/auth", authRoutes); // auth + profile + bookmarks + password
app.use("/api/polls", pollRoutes); // polls + comments + vote + bookmark
app.use("/api/users", userRoutes); // profiles + follow
app.use("/api/notifications", notificationRoutes); // notifications

// 6. Start listening on port 5000
app.listen(5000);

🔐 middleware/auth.js — JWT Verification

Two middleware variants are exported:

ExportBehaviorWhen to Use
auth (default)If no token → 401. If invalid token → 401. Sets req.userId from decoded JWT.Protected endpoints (create poll, vote, bookmark, etc.)
optionalAuthIf token present → decode & set req.userId. If missing/invalid → continue silently with no userId.Public endpoints where personalized data is nice (poll feed shows bookmarks if logged in)
// auth.js — extracts Bearer token, verifies, attaches userId
const header = req.headers.authorization || "";
const token = header.startsWith("Bearer ") ? header.split(" ")[1] : null;
if (!token) return res.status(401).json({ message: "No token provided" });
const decoded = jwt.verify(token, process.env.JWT_SECRET);
req.userId = decoded.id;
next();

📋 Controllers — Business Logic (7 files)

controllers/authController.js

Authentication Controller

Handles user registration (with avatar upload + OTP email), OTP verification, login, profile retrieval/update, password change.
register()
Checks duplicates, uploads avatar to Cloudinary, generates OTP, creates User with isVerified:false, sends OTP email
verifyOtp()
Finds user by email, validates OTP (code + expiry), marks isVerified:true
login()
Validates email + password via bcrypt, checks isVerified, returns JWT + user data
getProfile()
Returns user + poll stats (created, voted, followers, following) + enriched polls
updateProfile()
Updates name/username/bio/avatar with duplicate username check
updatePassword()
Validates current password, sets new password (hashed by pre-save hook)
controllers/passwordController.js

Password Reset Controller

OTP-based password reset flow, no login required.
forgotPassword()
Finds user by email, generates OTP, saves OTP to user doc, sends OTP email
verifyResetOtp()
Validates OTP without changing password yet — frontend uses this to confirm before showing new-password form
resetPassword()
Verifies OTP one more time, hashes new password, clears OTP fields
controllers/pollController.js

Poll Controller (12 functions — the largest file)

Full CRUD + voting + stats for polls.
getMyPolls()
Polls where creator = current user. Enriched with comment counts + bookmark status.
getVotedPolls()
Polls where votes array contains current user's ID.
getTrending()
MongoDB aggregation: group polls by type, count, sort descending.
getPolls()
All polls with optional type/category/following filters. Enriched with comment + bookmark data.
getPoll()
Single poll by ID. Populates creator + voters. Increments view count (unless creator or ?noview=true).
createPoll()
Creates poll with type-specific option normalization. Image type uploads to Cloudinary. Populates creator.
votePoll()
Validates value per type. Finds existing vote → update; or push new vote. Creates Notification for creator. Repopulates + returns.
unvotePoll()
Removes user's vote from votes array. Deletes associated notification.
editPoll()
Updates question/category. Owner-only check.
closePoll()
Toggles poll.closed boolean. Owner-only.
deletePoll()
Owner-only delete. Removes whole poll document.
getStats()
Aggregate counts: total polls, total votes, active users (unique voters), avg votes/poll.
controllers/commentController.js

Comment Controller

Threaded comments on polls.
addComment()
Creates comment with optional parentComment for replies. Creates notification for poll creator.
getComments()
Returns all comments for a poll, populated with user details. Frontend separates top-level vs replies.
deleteComment()
Only comment author can delete.
controllers/bookmarkController.js

Bookmark Controller

Toggle-style bookmark on polls, stored in User's bookmarks array.
bookmarkPoll()
If poll ID already in user.bookmarks → remove (unbookmark). Otherwise → push (bookmark). Returns current bookmarks array.
getBookmarks()
Returns full poll details for all bookmarked polls, with nested populate (creator).
controllers/followController.js

Follow Controller

Follow/unfollow users. Stored in User.following array.
followUser()
Adds target to current user's following. Prevents self-follow. Creates follow notification.
unfollowUser()
Removes target from current user's following array.
getConnections()
By username: returns follower docs (users who follow this user) + following docs (users this user follows).
controllers/notificationController.js

Notification Controller

Read/unread notification management.
getNotifications()
Returns 50 latest notifications for current user, with actor + poll populated. Includes unreadCount.
markAsRead()
Sets one notification's read flag to true (ownership-checked).
markAllAsRead()
Bulk update: all unread notifications for this user → read:true.

🧰 Utils & Config — Helper Layer

utils/computeResults.js

Vote Computation Engine

Three pure/reusable functions that power the entire polls system.
computeResults(poll)
Takes poll document, returns result array per type. For yesno: yes/no counts + percentages. For single: per-option counts + %. For rating: 1-5 star distribution. For image: per-image counts + %. For open: all text responses.
enrichPoll(poll, userId)
Converts poll to plain object. Finds user's vote (myVote). Adds totalVotes count. Calls computeResults() and attaches results array.
bookmarkSet(userId)
Queries User's bookmarks array, returns a Set of poll IDs for O(1) lookup on each poll.
utils/generateOTP.js

OTP Generator

generateOTP()
Returns random 6-digit string (e.g. "482917") via Math.random().
expireOTP()
Returns Date object 10 minutes from now.
otpValid(user, otp)
Checks if provided OTP matches user.otp.code AND Date.now() < user.otp.expiresAt.
utils/mailer.js

Email Sender

sendMail({ to, subject, text })
Sends email via config/mailer.js transporter. Returns true on success, false on failure (never throws).
config/cloudinary.js

Cloudinary + Multer

Dual purpose: (1) Multer middleware for parsing file uploads into memory buffers. (2) Cloudinary upload function that streams buffer to cloud.
upload
Multer instance configured with memoryStorage for avatar + poll images.
uploadToCloudinary(buffer)
Takes image buffer, uploads via cloudinary.uploader.upload_stream(), returns secure URL. Never throws (caller catches).
config/db.js

Database Connection

connectDB()
Calls mongoose.connect(MONGO_URI). Logs success. On error, logs and exits process.
config/mailer.js

SMTP Transporter

transporter
Nodemailer createTransport() using SMTP host/port/auth/user/pass from .env.

🔄 Complete Request Lifecycle

Rule: Each layer ONLY talks to the layer next to it. Controllers never call routes. Models never call controllers.

End-to-End Request Flow


Public: skips middleware, goes straight to controller 5. Controller handles business logic Validates input, calls Model methods, calls utils (OTP, email, upload), builds response 6. Model executes database operation await User.findOne({ email }) → Mongoose translates to MongoDB query → returns document 7. MongoDB processes and returns data 8. Controller sends JSON response res.json({ token: 'eyJhbG...', user: { id, name, email } }) 9. Browser receives JSON

Concrete Example: Creating a Poll

Frontend sends POST /api/polls
api.post("/polls", { question: "Best tech?", type: "single", options: ["React","Vue","Svelte"] })
server.js mounts /api/polls
app.use("/api/polls", pollRoutes);
pollRoutes matches POST /
router.post("/", auth, createPoll); // auth middleware runs first
auth middleware verifies JWT, attaches userId
req.userId = decoded.id; // userId available in controller
createPoll() validates input, creates Poll document
await Poll.create({ creator: req.userId, question, type, options });
Poll is saved to MongoDB, response returned
res.status(201).json({ poll }); // frontend receives the poll

JWT Token Flow

AspectDetails
GenerationauthController.login() calls generateToken(user._id) → jwt.sign({ id }, JWT_SECRET, { expiresIn: JWT_EXPIRE })
StorageFrontend stores token in localStorage under key "token"
Transmissionapi.js adds Authorization: Bearer token header on every request
Verificationmiddleware/auth.js: jwt.verify(token, JWT_SECRET) → extracts decoded.id → sets req.userId
ExpirySet by JWT_EXPIRE env var (typically 7-30 days)
LogoutFrontend removes token + user from localStorage
